# INC

一个基于原生 JavaScript 开发的 Incremental Game（增量游戏 / 放置游戏）项目。

项目目标是探索大型数字系统、资源增长模型、多阶段重置机制以及数据驱动的游戏架构设计。

## Features

- 无限增长的资源系统
- 超大数字计算支持
- Infinity（无限）重置机制
- 永久成长系统
- Upgrade 升级系统
- Achievement 成就系统
- Challenge 挑战系统
- 自动保存与读取
- 模块化 UI 渲染
- 浏览器原生运行，无需构建工具

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Decimal.js / break_eternity.js

项目完全基于原生 Web 技术实现，没有使用前端框架。

---

### Run Locally

直接打开：


index.html


即可运行。

也可以使用任意静态服务器：

例如：


python -m http.server


然后访问：


http://localhost:8000
